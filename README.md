# kidguard_site

Public pages for the kidguard Android app, served by GitHub Pages:
https://danhbuidcn.github.io/kidguard_site/

| Page | Path |
| --- | --- |
| Home | `index.html` |
| User guide (parent / child) | `guide/parent.html`, `guide/child.html` |
| Terms of use | `legal/terms.html` |
| Privacy policy (account deletion: `#delete`) | `legal/privacy.html` |

`guide/` and `legal/` are copies. Edit the source in the kidguard repo (`docs/02-ui-design/user-guide`, `docs/02-ui-design/legal`), then run `scripts/publish-site.sh` there and commit here.
